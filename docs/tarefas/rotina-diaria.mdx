# Rotina diária

Use esta rotina quando você precisa acompanhar vários monitoramentos sem transformar a plataforma em uma lista infinita de leitura.

## Antes de começar

Você precisa ter acesso ao workspace e saber qual cliente, marca ou tema está acompanhando naquele dia.

## 1. Comece pelo Dashboard

Abra o **Dashboard** e observe três coisas:

1. quais casos estão ativos;
2. quais casos mudaram de prioridade;
3. quais casos precisam de leitura humana antes de qualquer ação.

**Resultado esperado:** você sai com uma lista curta de casos para revisar primeiro.

Se tudo parecer igualmente urgente, comece pelos casos com maior risco, maior exposição pública ou decisão pendente.

## 2. Abra o caso mais importante

No caso, leia nesta ordem:

1. **Resumo** — para entender o estado geral;
2. **Contexto** — para lembrar o histórico e o motivo do monitoramento;
3. **Cobertura** — para ver sinais recentes;
4. **Ações** — para verificar encaminhamentos abertos.

**Resultado esperado:** você entende se o caso está estável, em atenção ou exigindo resposta.

## 3. Atualize o que mudou

Registre somente mudanças que ajudam decisão:

- novo fato relevante;
- nova reação pública;
- mudança de prioridade;
- decisão tomada;
- próximo responsável ou próxima ação.

Evite registrar leitura duplicada ou opinião sem evidência clara.

## 4. Use a Cris para reduzir ruído

Peça ajuda à Cris quando precisar sintetizar ou comparar informações.

Exemplos de pedido:

- “Resuma o estado deste caso em três pontos.”
- “Quais lacunas ainda impedem uma decisão?”
- “Que próximo passo é mais seguro com base no que está registrado?”

A resposta da Cris deve apoiar a leitura. A decisão final continua humana.

## 5. Feche o ciclo do dia

Antes de encerrar, confirme:

- quais casos continuam ativos;
- quais ações ficaram pendentes;
- quem precisa receber atualização;
- se há relatório, síntese ou registro que precisa ser preparado.

**Resultado esperado:** o próximo leitor entende o estado do caso sem depender da sua memória.

## Quando algo parece errado

Se cobertura, score ou contexto parecerem incoerentes:

1. volte ao histórico do caso;
2. compare com a cobertura mais recente;
3. registre a dúvida como lacuna;
4. peça revisão humana antes de agir como se o dado estivesse confirmado.

Consulte também [Recuperação e dúvidas comuns](/tarefas/recuperacao).
