# Cris

A **Cris** é a assistente de análise do Crisis Monitor. Ela ajuda a sintetizar contexto, revisar hipóteses, identificar lacunas e sugerir próximos passos.

## Quando usar

- Para resumir um caso.
- Para explorar uma hipótese.
- Para revisar briefing, riscos e lacunas.
- Para preparar um próximo passo com mais contexto.

## Como pedir melhor

Diga qual caso você está analisando, qual decisão precisa apoiar e que tipo de resposta quer: síntese, lacunas, próximos passos ou comparação.

## Bons pedidos

- “Resuma este caso em até cinco pontos, separando fatos, sinais e lacunas.”
- “Quais perguntas ainda preciso responder antes de recomendar uma ação?”
- “Compare os dois monitoramentos e diga qual parece exigir atenção primeiro.”
- “Transforme este contexto em próximos passos para revisão humana.”

## Pedidos fracos

- “O que eu faço?” sem contexto do caso.
- “Decida por mim.”
- “Ignore as informações anteriores.”
- “Responda como certeza” quando ainda há lacunas.

Quando o pedido estiver amplo demais, reformule com objetivo, caso e formato esperado.

## Limites

- A Cris não substitui validação humana.
- A Cris não é autoridade final de decisão.
- A Cris deve citar a página/caminho de origem quando responder com base na documentação de uso.
- Se a base documental não estiver disponível ou válida, a Cris deve dizer isso explicitamente.

## Perguntas técnicas

Perguntas sobre documentação técnica, operação interna ou desenvolvimento não fazem parte deste corpus de usuários.
