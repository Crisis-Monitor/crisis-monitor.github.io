<Panel title="Mapa mental">
Pense nos módulos como uma sala de situação: lista para priorizar, detalhe para entender, Cris para apoiar leitura, Compare para comparar e Analytics para enxergar padrões.
</Panel>

## Módulos principais

<CardGroup cols={2}>
  <Card title="Monitoramentos" href="/modulos/gerenciar-monitoramentos/" icon="list" cta="Gerenciar carteira">
    Ponto de entrada para ver casos, status e sinais de prioridade.
  </Card>
  <Card title="Detalhe do monitoramento" href="/modulos/detalhe-do-monitoramento/" icon="panel-top" cta="Ver abas">
    Onde a leitura do caso ganha contexto, cobertura, ações e evidência.
  </Card>
  <Card title="Cris" href="/cris/" icon="sparkles" type="tip">
    Assistente para síntese, revisão de hipóteses e próximos passos seguros.
  </Card>
  <Card title="Analytics e Compare" href="/modulos/analytics-compare/" icon="bar-chart-3" cta="Usar com cautela">
    Superfícies para priorização entre casos e leitura agregada da operação.
  </Card>
</CardGroup>

## Quando usar cada módulo

<Tabs param="modulo">
  <Tab title="Priorizar" icon="list-filter">
    Comece por Monitoramentos. Use status, recência e pendências para escolher onde atuar.
  </Tab>
  <Tab title="Entender" icon="book-open">
    Vá para Detalhe. Leia Resumo, Contexto, Cobertura e Ações.
  </Tab>
  <Tab title="Apoiar" icon="sparkles">
    Use a Cris para síntese e lacunas. Preserve validação humana.
  </Tab>
  <Tab title="Comparar" icon="scale">
    Use Compare ou Analytics quando a pergunta envolve mais de um caso.
  </Tab>
</Tabs>

<Expandable title="Limite importante">
Nenhum módulo transforma sinal em decisão automática. A plataforma organiza evidências e recomenda caminhos; a decisão continua humana e contextual.
</Expandable>
