# Módulos da plataforma

## Dashboard

Visão geral do workspace ativo. Use para priorizar casos, decidir por onde começar o dia ou encontrar um monitoramento específico.

## Monitoramentos

Área de criação e gestão dos casos monitorados. Use ao abrir novos monitoramentos, revisar status ou entrar no detalhe de cada caso.

## Detalhe do monitoramento

Workspace completo de um caso específico. Use para manter briefing, leitura operacional, evolução, registro e síntese conectados.

## Cris

Assistente de análise da plataforma. Use para sintetizar contexto, sugerir próximos passos, revisar hipóteses e acelerar leitura sem esconder incerteza.

## Compare

Superfície comparativa entre monitoramentos. Use quando houver disputa por atenção ou necessidade de priorização executiva.

## Analytics

Camada de métricas e auditoria. Use para acompanhar KPIs, uso do wizard, auditoria de IA e sinais agregados do workspace.

## Media Tiers

Catálogo editorial das fontes monitoradas. Use para calibrar influência, cobertura mínima e relevância das fontes.

## Configurações

Área administrativa e operacional. Use para membros, convites, alertas, integrações, rotinas e checagens de saúde.
