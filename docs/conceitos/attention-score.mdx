# Attention Score

O **Attention Score** é um indicador sintético de atenção do caso. Ele ajuda a priorizar leitura e ação, mas não substitui julgamento humano.

## Como usar

- Use para comparar pressão relativa entre casos.
- Combine o score com cobertura, contexto e histórico.
- Revise evidências antes de tomar uma decisão sensível.

## Limite

Um score alto indica necessidade de atenção. Ele não define sozinho a resposta, a fase do caso ou a comunicação externa.
